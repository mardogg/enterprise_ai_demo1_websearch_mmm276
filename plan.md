Customer issue: my macbook air's screen half blacked out
================================================================================

Result:
## Quick Hypotheses
- Faulty display or display connector
- Graphics card/driver issues
- Software conflicts or operating system corruption
- Hardware failure (e.g., logic board issues)
- Physical damage to the screen

## Diagnostics (Step-by-Step)
1. Restart the MacBook Air and observe if the issue persists.
   - If success: No further action needed; issue was temporary.
   - If fails: Proceed to step 2.
   
2. Connect an external display to check if the problem lies with the internal screen.
   - If success: Internal display issue confirmed; check hardware or connections.
   - If fails: Proceed to step 3.

3. Boot into safe mode (hold Shift key during startup) to see if the issue is software-related.
   - If success: Investigate recent software changes or updates.
   - If fails: Likely a hardware problem; consider component testing.

## Safety & Data-Loss Warnings
- Always back up important data before performing diagnostics.
- Disconnect all peripherals to avoid electrical interference during testing.

## Fix Paths
- If external display works, check and reseat internal display connectors.
- If software issues are found, reinstall macOS or remove problematic software.
- For persistent hardware errors, replace the display or logic board based on diagnostics.

## When to Escalate
- If hardware components need replacement or advanced troubleshooting is required.
- If diagnostics indicate potential logic board failure.
- If internal components are inaccessible or require specialized tools for repair.
